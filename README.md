# PyWxDump 4.0.0 · 使用说明

> 本文件同时存放于两个私有仓库（源码库 `dbtool-4x-src`、文档库 `dbtool-4x-docs`），内容一致。
> 版本 **4.0.0** ｜ 最后更新 **2026-10-04**

---

## 一、这是什么

一个运行在本机 Windows 上的**本地数据备份与导出工具**：只读读取本机已登录客户端的本地数据库副本，把聊天记录汇总导出，并提供一个网页界面用于查看会话、聊天记录与统计图表。

- 只在本机运行，**不联网上传任何数据**
- 全程**只读**：不向客户端进程写入任何内容、不修改客户端文件、不改动系统设置
- 支持微信 4.x（已在 4.1.15.13 版本验证通过）

---

## 二、环境要求

| 项目 | 要求 |
| --- | --- |
| 操作系统 | Windows 10 / 11（64 位） |
| Python | 3.12（安装时勾选 Add Python to PATH） |
| 客户端 | 微信 4.x，**已登录并保持运行**（读取密钥需要进程存在） |
| 权限 | 普通用户即可，**无需管理员** |
| 磁盘空间 | 建议预留 3～10 GB 存放本地数据副本 |
| 依赖库 | 由 pip 自动安装（清单见 `pyproject.toml`） |

## 三、安装步骤（从零开始）

**第 1 步：下载源码**

在私有仓库页面点击 `Code` → `Download ZIP`，解压到固定目录：

```
D:\PyWxDump_Source
```

> 路径建议**不含中文、不含空格**，避免个别依赖解析失败。

**第 2 步：打开 PowerShell 并进入目录**

```powershell
cd /d D:\PyWxDump_Source
```

**第 3 步：（推荐）创建独立运行环境**

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
```

> 若提示"禁止运行脚本"，先执行下面这条再重试：
> `Set-ExecutionPolicy -Scope Process RemoteSigned`

**第 4 步：安装（可编辑模式）**

```powershell
pip install -e .
```

**第 5 步：验证安装**

```powershell
wxdump -h
```

标题栏显示 `PyWxDump v4.0.0` 即安装成功（也可用 `wxdump -V`）。

> 若提示"`wxdump` 不是内部或外部命令"，改用 `python -m pywxdump -h`，或把 Python 安装目录下的 `Scripts` 文件夹加入系统 PATH 后重开 PowerShell。

## 四、首次使用（三步）

**第 1 步**：登录微信客户端，并**保持运行**（不要关闭）。

**第 2 步：读取本机账号与数据密钥**

```powershell
wxdump info
```

输出里出现 `key_source: memory` 表示密钥已从内存成功读取。

**第 3 步：打开网页界面**

```powershell
wxdump ui
```

- 浏览器会自动打开（默认地址 `http://127.0.0.1:17953`）
- 首次进入会自动准备本地数据副本，数据量大时需要等几分钟
- 在「选择要查看的微信」页面点【确定】，即可进入会话列表

> UI 运行期间**不要关闭** PowerShell 窗口；关闭窗口就等于停止服务。退出请按 `Ctrl + C`。

## 五、常用命令清单

| 命令 | 一句话说明 |
| --- | --- |
| `wxdump info` | 显示当前账号信息与数据密钥清单（含来源标记） |
| `wxdump bias` | 显示密钥与数据库文件的对应关系 |
| `wxdump ui` | 启动网页界面：会话列表、聊天记录、统计与热力图 |
| `wxdump api` | 只启动后端接口服务（默认 5000 端口，供其他脚本调用） |
| `wxdump wx_path` | 显示／定位本机数据根目录（微信 4.x 通常为 `D:\xwechat_files`） |
| `wxdump dbshow` | 查看某个数据库的表结构与内容 |

**补充参数（按需使用）**

```powershell
wxdump api --port 8081                          # 换接口端口（默认 5000）
wxdump ui -p 8081                               # 换界面端口（默认 17953）
wxdump dbshow --db_path "D:\某个库.db"           # 指定数据库文件（别名 --db）
wxdump info --key_file "C:\路径\all_keys.json"   # 内存读不到时，改用本地密钥文件
```

## 六、多账号切换

1. 在客户端切换到目标账号，并确认**已登录完成**。
2. **先跑一次取密钥命令**：

```powershell
wxdump info
```

3. **再打开界面**：

```powershell
wxdump ui
```

4. 若界面仍显示上一个账号：按 `Ctrl + C` 关闭服务，重新执行 `wxdump ui`；必要时在界面里手动选择账号。

> 不同账号的数据副本按账号分别存放，互不覆盖，可随时切回。

## 七、备份与恢复

**需要备份的三样东西**

| 项 | 位置 | 说明 |
| --- | --- | --- |
| 源码与配置 | `D:\PyWxDump_Source\` | 备份时排除 `wxdump_work\`、`__pycache__\` |
| 本机密钥文件 | `C:\Users\Administrator\.wechat-cli\` | **含本机密钥，切勿上传、切勿分享** |
| 已准备的本地数据副本 | `C:\Users\Administrator\wxdump_work\` | 体积较大，可按需只保留账号子目录 |

**恢复（换机或重装后）**

1. 还原源码目录 → 执行 `pip install -e .`
2. 把密钥文件与工作目录还原到上面的原路径
3. 执行 `wxdump info` 验证密钥可用
4. 执行 `wxdump ui` 打开界面

> 建议做法：**源码**放进 Git 私有仓库；**密钥文件与数据副本**单独存放（本地加密盘或移动硬盘），永远不要上传。

## 八、常见问题 FAQ

**Q1：`wxdump info` 里手机号／邮箱显示 None，是坏了吗？**

不是。新版客户端不再把手机号、邮箱放在可读取的位置，工具只输出能读到的字段。账号与数据密钥不受影响，功能正常。手机号可在客户端「我 → 个人信息」里自行核对。

**Q2：某段聊天记录读不出来，或列表里找不到某个会话？**

按顺序排查：

1. 该会话是否属于**当前登录的账号**（切号后要先 `wxdump info`，再 `wxdump ui`）；
2. 本地数据副本是否完整——重新执行 `wxdump ui`，让工具重新准备一次副本；
3. 是否是非常新的消息——在客户端里点开该会话后，刷新界面再看。

**Q3：界面报 `Network Error`，或提示"未获取到数据库路径"？**

先确认 PowerShell 窗口没有关闭（后端服务还在跑），然后刷新浏览器页面。仍失败时直接重启一次：

```powershell
wxdump ui
```

新版启动会**自动定位账号与数据目录**，不需要手动填任何路径。

**Q4：每次读到的密钥数量不一样，正常吗？**

正常。内存中可能同时存在多个账号、多个历史库的密钥，且客户端会动态加载；工具只保留通过校验的密钥，所以数量会小幅波动。判断是否正常，以 `wxdump ui` 能否顺利打开会话为准。

**Q5：换一台新电脑怎么部署？**

按「三、安装步骤」装好 → 把**密钥文件**与**本地数据副本**还原到原路径 → `wxdump info` 验证 → `wxdump ui`。若内存读取失败，用 `--key_file` 指定密钥文件即可。

**Q6：提示 `Port 5000 is already in use`？**

端口被占用，两种处理方式，任选其一：

```powershell
wxdump api --port 8081     # 换一个端口启动
wxdump api --killPort      # 自动结束占用该端口的进程（不加该参数时，会自动换一个空闲端口）
```

**Q7：提示 `wxdump` 不是内部或外部命令？**

两种办法：① 用 `python -m pywxdump info` 代替；② 把 Python 安装目录下的 `Scripts` 文件夹加入系统 PATH，重开 PowerShell。

**Q8：界面里某个群的聊天记录为空？**

多数情况是该群消息分散存储在多个分片库中，或该群属于其他账号。先确认账号正确，再重新准备一次副本（重跑 `wxdump ui`）。
